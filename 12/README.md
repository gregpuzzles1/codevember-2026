# Feather

A three.js field-guide exhibition of 26 birds from the Northern Colorado list. Select a bird to see its field note and drag the scene to rotate the featured model. Browse the bird grid by scrolling down.

Run a static server from this folder:

```sh
python -m http.server 8765
```

Open `http://localhost:8765`. An internet connection is required to load three.js and the fonts.

The bird models are original stylized interpretations, not identification-grade representations. The close-up is normalized for visibility; the field note compares approximate adult body lengths with a house sparrow. Broad names such as duck, goose, gull, swallow, blackbird, and dove are represented by specific species. The great cormorant is included as requested, but is rare inland in Colorado.
