## Updating the calendar

When a numbered day folder contains both `index.html` and a `social-preview` image (PNG, JPG, JPEG, WebP, or SVG), the Pages workflow updates the calendar and this list automatically after a push to `main`. Place the image in the day folder or its `public` subfolder. New README entries use the day folder's README heading, or the prompt word if there is no heading.

To update both files locally, run `node scripts/update-days.cjs` from the repository root. The workflow commits generated updates to `main` and deploys them. The workflow builds Day 22 with Vite; other projects requiring a build need a corresponding deployment step.
