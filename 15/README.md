# Mirage

A shimmering desert oasis for Codevember Day 15, made with Three.js. Adjust the heat haze to change the oasis's shimmer, and use Pause to freeze the scene. The scene starts paused when reduced motion is requested.

Run a static server from this folder:

```sh
python -m http.server 8765
```

Open `http://localhost:8765`. An internet connection is required to load Three.js and the fonts.
